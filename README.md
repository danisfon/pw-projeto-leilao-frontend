# 💻 Frontend - Plataforma de Leilões

Frontend da aplicação de leilões, desenvolvido com **React**. O sistema permite cadastro, login, visualização e participação em leilões.

## 🚀 Tecnologias

- React
- React Router
- SweetAlert2

## 📚 Funcionalidades

- Autenticação (login/cadastro)
- ...

## 🛠️ Como executar

```bash
git clone https://github.com/danisfon/leilao-frontend.git
cd leilao-frontend
npm install
npm start
```
